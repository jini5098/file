# 동글 변환기

파일 둘레에 동그랗게 뜨는 버튼에서 형식을 고르면 바로 변환해 주는 도구.
웹 버전과 윈도우 데스크톱 버전이 한 저장소에 들어 있다.

## 쓰는 법 (윈도우)

| 방법 | 하는 일 |
| --- | --- |
| 파일 위에서 **Alt + 우클릭** | 윈도우 메뉴 대신 그 자리에 동글이 뜬다 |
| **Shift + 우클릭** → "동글로 변환" | 윈도우 11. 윈도우 10은 그냥 우클릭 메뉴에 보인다 |
| 파일 선택 후 **Ctrl + Shift + D** | 여러 파일을 한꺼번에 바꿀 때 편하다 |
| 트레이(시계 옆) 빨간 동그라미 클릭 | 파일을 골라서 변환 |

- 변환한 파일은 **원본 옆에** 저장된다. 같은 이름이 있으면 `이름 (2)`로 저장한다.
- 동글 바깥을 누르거나 Esc를 누르면 닫힌다.
- 트레이 아이콘을 우클릭하면 각 기능을 켜고 끌 수 있다.

## 바꿀 수 있는 형식

| 넣는 파일 | 바꿀 수 있는 형식 |
| --- | --- |
| 사진 (PNG, JPG, WEBP, GIF, BMP, SVG) | PNG, JPG, WEBP, PDF |
| PDF | PNG, JPG, TXT (여러 쪽이면 ZIP) |
| CSV | JSON, 엑셀, MD 표, HTML 표 |
| JSON | CSV, 엑셀, TXT |
| 엑셀 | CSV, JSON, HTML |
| MD / HTML / TXT | 서로 변환 |

파일은 어디로도 올라가지 않고 내 컴퓨터 안에서만 바뀐다.

## 깃허브에 올려서 설치 파일 받기

내 PC에 아무것도 설치하지 않아도 깃허브가 대신 만들어 준다.

1. 깃허브에서 새 저장소를 만든다 (예: `donggeul`, Public).
2. 이 폴더 안의 파일을 전부 올린다. `.github` 폴더도 꼭 같이 올린다.
3. 저장소의 **Actions** 탭에서 "윈도우 설치 파일 만들기"가 도는 것을 기다린다 (5~10분).
4. 끝나면 **Releases**에 `Donggeul-Setup-0.1.0.exe`가 생긴다. 받아서 실행한다.
5. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누른다 (서명이 없는 개인 프로그램이라 뜨는 창).

Actions에 빨간 X가 뜨면 그 화면의 오류 글자를 복사해서 Claude에게 보여주면 된다.

## 소개 사이트 열기 (깃허브 페이지)

저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/docs`로 고르면
`https://<아이디>.github.io/<저장소>/` 주소로 소개 사이트가 열린다.

- 소개 사이트에는 연습용 바탕화면이 있어서 설치 전에 우클릭 → 동글 → 변환을 직접 해볼 수 있다.
- "윈도우용 받기" 버튼은 이 저장소 Releases의 최신 설치 파일로 자동 연결된다. 주소를 따로 적을 필요가 없다.
- 설치 없이 쓰는 웹 버전은 `app.html`이다.

## 내 PC에서 직접 돌려보기 (선택)

Node.js가 있으면:

```
npm install
npm start -- "C:\어떤\파일.png"
```

Alt+우클릭 도우미까지 쓰려면 AutoHotkey v2의 `AutoHotkey64.exe`를 `helper` 폴더에 넣는다.

## 지우기

트레이 메뉴에서 "우클릭 메뉴에 넣기"를 끈 다음, 윈도우 설정 → 앱에서 Donggeul을 제거한다.

## 파일 구조

- `main.js` 본체: 트레이, 동글 창, 우클릭 메뉴 등록, 도우미 실행
- `ring.html` 동글 화면
- `core.js` 변환 코드 (웹 버전과 같음)
- `helper/donggeul.ahk` Alt+우클릭·단축키를 잡는 도우미 (AutoHotkey v2)
- `vendor/` PDF·엑셀을 읽는 도구 (pdf.js, SheetJS — Apache-2.0)
- `docs/index.html` 소개 사이트 (체험 + 받기)
- `docs/app.html` 웹 버전
- `.github/workflows/build.yml` 깃허브가 설치 파일을 만드는 순서

도우미로 쓰는 AutoHotkey는 GPLv2 프로그램이며 빌드할 때 공식 배포판을 그대로 받아 넣는다.
