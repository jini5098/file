윈도우용 받기

진짜 바탕화면에서는 이렇게

세 가지 중 편한 걸로.

Alt+

Alt + 우클릭

파일 위에서 누르면 윈도우 메뉴 대신 동글이 바로 떠.

Shift+

우클릭 메뉴

메뉴 맨 위 "동글로 변환". 윈도우 10은 Shift 없이도 보여.

Ctrl+Shift+D

여러 개 한꺼번에

파일을 여러 개 고르고 누르면 전부 같은 형식으로 바꿔.

바꿀 수 있는 형식

영상과 소리는 아직 없어.

사진→PNGJPGWEBPPDF
PDF→PNGJPGTXT
CSV · 엑셀→JSONXLSXCSVHTML
JSON→CSVXLSXTXT
MD · HTML · TXT→MDHTMLTXT
여러 파일→한 번에 같은 형식으로

알아둘 것

파일이 밖으로 안 나가변환은 전부 내 컴퓨터 안에서 해. 서버에 올리지 않아.
원본은 그대로새 파일을 원본 옆에 따로 만들어. 같은 이름이 있으면 (2)를 붙여.
무료, 광고 없음코드도 깃허브에 전부 공개돼 있어.

받기

윈도우용 설치 파일 받기 설치 없이 웹에서 쓰기
  1. 받은 Donggeul-Setup 파일을 실행해.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행. 개인이 만든 프로그램이라 뜨는 창이야.
  3. 시계 옆에 빨간 동그라미가 생기면 준비 끝. 파일 위에서 Alt+우클릭.
